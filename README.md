# 🛒 Supermarket

>
> # 🛒 Supermarket

Веб-приложение информационной системы «Супермаркет», разработанное в рамках дипломной работы по специальности 09.02.07 «Информационные системы и программирование».

## 📋 Описание проекта

Проект представляет собой интернет-магазин для автоматизации процессов продажи товаров. Система позволяет пользователям просматривать каталог продукции, добавлять товары в корзину, оформлять заказы и взаимодействовать с системой через удобный веб-интерфейс.

Также реализована административная панель для управления товарами и заказами.

## 🚀 Основные возможности

### Пользовательская часть
- Просмотр каталога товаров
- Регистрация и авторизация пользователей
- Добавление товаров в корзину
- Изменение количества товаров
- Удаление товаров из корзины
- Оформление заказа
- Просмотр информации о заказе

### Административная часть
- Просмотр списка товаров
- Добавление новых товаров
- Редактирование товаров
- Удаление товаров
- Просмотр заказов пользователей
- Управление данными системы

## 🏗 Архитектура проекта

Проект построен по принципу клиент-серверного веб-приложения.

Пользователь взаимодействует с системой через браузер, запросы обрабатываются серверной частью на PHP, данные хранятся в реляционной базе данных MySQL.

Основные компоненты:

- Router — обработка маршрутов приложения;
- Controllers — бизнес-логика приложения;
- Views — HTML-шаблоны пользовательского интерфейса;
- MySQL — хранение данных системы.

## 🗄 Структура базы данных

Основные таблицы:

| Таблица | Назначение |
|---------|-------------|
| users | данные пользователей |
| products | информация о товарах |
| orders | информация о заказах |
| order_items | состав заказов |

## ⚙ Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/lilclipse/supermarket.git
cd supermarket
```

### 2. Установка зависимостей

```bash
composer install
```

### 3. Настройка базы данных

1. Создайте базу данных MySQL.
2. Импортируйте SQL-файл проекта.
3. Настройте параметры подключения к базе данных.

### 4. Запуск проекта

Запустите Apache и MySQL через XAMPP и откройте приложение в браузере:

```text
http://localhost/supermarket/
```
